\section{Cumplimiento progresivo del plan de prácticas pre profesionales }

El puesto de Desarrollador de Software Frontend Junior en la Dirección de Proyección Social y Extensión Cultural desempeña un rol clave en el diseño, desarrollo y mantenimiento de soluciones tecnológicas que optimicen la operación de la institución. Este puesto no solo requiere habilidades técnicas en desarrollo frontend, sino también una comprensión profunda de los procesos institucionales para garantizar que las soluciones propuestas sean eficientes, de alta calidad, y alineadas con las necesidades específicas de la universidad.

Para garantizar un desarrollo ágil y eficiente, el proyecto adoptará la metodología SCRUM, una de las metodologías ágiles más populares

\section{Conclusiones}
La implementación de la metodología Extreme Programming (XP) permitió un desarrollo ágil y colaborativo, cumpliendo el 100\% del plan con hitos clave como análisis de requerimientos (10 funcionales y 3 no funcionales), diseño de interfaces (90\% de madurez en Figma), desarrollo de backend (API RESTful con Node.js/Express, JWT, PostgreSQL y Prisma) y frontend (Next.js/Tailwind CSS al 90\%), y pruebas parciales de seguridad (40\%). SCRUM optimizó la calidad del software y la comunicación con el equipo. Se adquirieron habilidades técnicas (Figma, Prisma, Next.js), gestión de proyectos (GitHub, priorización) y competencias blandas (comunicación con usuarios). Los resultados demuestran un sistema funcional, aunque se recomienda completar pruebas y reforzar la retroalimentación continua.
\section{Recomendaciones}
Para mejorar el proyecto, se sugiere: 1) Reforzar SCRUM con retroalimentación semanal con usuarios para validar funcionalidades y ajustar requerimientos, evitando desfases. 2) Automatizar despliegues con CI/CD (GitHub Actions). 3) Completar el 60\% pendiente de pruebas con Jest (backend) y Cypress (frontend), e implementar pruebas de usuario (UAT). 4) Elaborar documentación técnica (manuales de API, instalación) y capacitar al personal. 5) Optimizar rendimiento con caching (Redis) y compresión de recursos para cumplir tiempos de carga (<2 segundos). 6) Reforzar seguridad con auditorías (OWASP ZAP) y autenticación de dos factores (2FA). Estas acciones asegurarán escalabilidad, calidad y adopción efectiva del sistema.
